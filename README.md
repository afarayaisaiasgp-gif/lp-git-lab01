
# Laboratorio 1 · Git y GitHub

Repositorio de práctica del curso Lenguajes de Programación (UPN 2026-2).

## Cómo ejecutar

Para ejecutar el programa, abre una terminal y escribe:

```bash
python promedio.py
```

El programa calcula el promedio final del estudiante utilizando los siguientes pesos:

- T1: 10 %
- EP: 20 %
- T2: 20 %
- EF: 50 %

El programa también valida que las notas estén entre 0 y 20.
